# Lab 8 Starter Code
This repository contains the code template for the Lab 8 Versioning systems developed for the course TIL6022 Python Programming at TU Delft in 2026.

## Instructions for Students

After receiving the assignment, modify the code in the Jupyter Notebook (.ipynb) and commit the changes you made. Each commit counts as one submission to Classroom50. It is recommended to change the code in the Jupyter Notebook directly. If you create a new Jupyter Notebook in the repository for grading, make sure you remove other Jupyter Notebooks that you do not wish to be graded. 

Each submission will trigger an autograding workflow to evaluate your updated Jupyter Notebook. To check the grading summary, go to Actions -> Autograde -> Click the workflow you want to check; the report is under grade/grade summary.   

> [!WARNING]
> Do not change the test file (test_lab8_2026.py).
> Do not change any of the file names.

## Instructions for Students

This lab is given in several parts. In part 1 you will work on Github on your own. In part 2 you will work together with your groupmates for the TIL main programming project. In part 3, you will contribute to Jialei's repository.

If you have not already, you will need to set up Git on your computer and connect it to your VS code. You can do the following:

- Install Git on your computer. You can follow [this link](https://git-scm.com/downloads).
- Login to Github in VS code to link your accounts. You can do this in the 'accounts' tab in the VS Code UI. 

You may need to restart your computer for changes to take effect.

## Part 1

- You have already created your own assignment repository by accepting this assignment.
- You will need to clone your repository, and follow the instructions in the notebook to create and work in a new branch.
- After you finish working on your notebook, you will need to merge your work back into the main branch.
- You will only need to change the file `lab8_2026_1.ipynb`

## Part 2

- To complete this part of the lab, you will need to meet up in your groups. 
- ONE of you will need to create a new repository, which is the main repository you will all work together on. 
- Follow the instructions provided in the file `lab8_2026_2.ipynb`
- MAKE SURE THE REST OF YOUR WORK HAPPENS IN THIS NEW REPOSITORY. You may remove this file from your personal repository.

When you are working in groups, you will often need to check each others code. You can do this by committing your changes to your branch and then make a pull request to merge into the main branch. Then, one of your groupmates can have a look at your code before approving it!

## Part 3

- This task should be completed individually
- Go to [this](https://github.com/TIL6022-Python-Programming/lab8_2026_together) repository and clone the repository as before.
- Before you continue, you will need to create your own branch. NAME THIS BRANCH THE SAME AS YOUR GITHUB ACCOUNT USERNAME.
- Follow the instructions provided in the file `lab8_2026_3.ipynb`
- Create a pull request to merge your changes into the main branch again
 


### Passing Criteria
- You will need to pass each task to pass the lab overall. Further instructions on passing criteria and how to check your passing status can be found in each individual file. 
- Part 1 will be checked by the autograder. You will need to pass 8/11 checks.
- Part 2 will be manually checked
- Part 3 will be manually checked

> [!WARNING]
> Do not use the "upload file" button to submit your final notebooks. Your Github history needs to show that you have followed the steps given in this lab.
